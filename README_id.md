# Cheat Engine — fork AzeoLXC

Ini adalah fork komunitas dari [Cheat Engine](https://github.com/cheat-engine/cheat-engine) yang dikelola AzeoLXC dan dirilis terpisah dari versi resmi Cheat Engine.

[Read in English](README.md)

## Unduh

Unduh versi terbaru dari [halaman rilis AzeoLXC](https://github.com/AzeoLXC/cheat-engine/releases). Pilih file sesuai arsitektur aplikasi yang ingin diperiksa:

- **x64** — untuk aplikasi 64-bit. Ini pilihan yang sesuai untuk sebagian besar game dan program Windows modern.
- **x86** — untuk aplikasi 32-bit.

Arsitektur Cheat Engine dan aplikasi target sebaiknya sama. Jika belum tahu, periksa apakah aplikasi target berjalan sebagai 32-bit atau 64-bit sebelum mengunduh.

## Mulai menggunakan Cheat Engine

1. Unduh dan buka rilis x86 atau x64.
2. Di Cheat Engine, pilih proses aplikasi yang sedang berjalan dan ingin diperiksa.
3. Cari nilai yang terlihat di aplikasi, seperti skor atau jumlah item.
4. Ubah nilai tersebut di aplikasi, lalu cari lagi nilai terbarunya untuk mempersempit hasil.
5. Setelah menemukan alamat yang cocok, pantau atau ubah nilainya melalui Cheat Engine.

Cheat Engine juga menyediakan debugger, disassembler, scripting Lua, dan alat untuk membuat trainer mandiri. Gunakan fitur ini hanya pada perangkat lunak yang kamu miliki atau yang boleh kamu periksa. Gunakan pada aplikasi offline dan ikuti ketentuan game atau perangkat lunak terkait; modifikasi game online dapat berdampak pada pemain lain dan melanggar aturan layanan.
