# Cheat Engine — AzeoLXC fork

This is a community-maintained fork of [Cheat Engine](https://github.com/cheat-engine/cheat-engine), maintained by AzeoLXC. It is separate from the official Cheat Engine release.

## Download

Get the latest files from the [AzeoLXC releases page](https://github.com/AzeoLXC/cheat-engine/releases). Choose the asset that matches the application you want to inspect:

- **x64** — for 64-bit applications. Use this for most modern Windows games and programs.
- **x86** — for 32-bit applications.

Cheat Engine and the target application should use the same architecture. If you are unsure, check whether the target program is 32-bit or 64-bit before downloading.

## Start using Cheat Engine

1. Download and open the x86 or x64 release.
2. In Cheat Engine, select the running process you want to inspect.
3. Search for a value you can observe in the application, such as a score or item count.
4. Change that value in the application, then search again for the new value to narrow the results.
5. When you have identified the matching address, you can monitor or edit it in Cheat Engine.

Cheat Engine also includes a debugger, a disassembler, Lua scripting, and tools for creating standalone trainers. These features are intended for software you own or are authorized to inspect. Use them with offline applications and follow the terms of the game or software you use; modifying online games can affect other players and may violate their rules.
